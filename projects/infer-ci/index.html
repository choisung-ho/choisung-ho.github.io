infer-ci 기반 AI 평가 신뢰구간 자동화

2026.10 – 진행 중 · 비인텔리전스글로벌 산학협력

프로젝트 간단 설명

㈜비인텔리전스글로벌과 우송대학교의 산학협력 프로젝트로, 현재 진행 중입니다. AI 모델의 Accuracy·F1-score 같은 성능 수치를 신뢰구간과 함께 제시할 수 있도록, 기존 infer-ci를 기반으로 평가 지표의 신뢰구간 산출을 자동화하는 평가 시제품을 만듭니다.

주 시도들

  1. Python으로 분류·회귀 평가 API 테스트를 작성했습니다.
  2. 작성한 테스트로 평가 지표의 신뢰구간 산출 결과를 검증하고 있습니다.
  3. 데이터 조건에 따라 분석적 방법과 Bootstrap 중 무엇을 적용할지 정하는 기준을 검토하고 있습니다.

기술 및 리소스

  • Python, infer-ci
  • 분류·회귀 평가 지표와 신뢰구간(분석적 방법, Bootstrap)

담당 역할

  • 분류·회귀 평가 API 테스트 작성
  • 신뢰구간 산출 검증

프로젝트 목표

  • 산업 AI 사례 1종과 얼굴 검증(1:1) 사례 1종 실증, 얼굴 식별(1:N) 기본 예제 1건
  • 조건별 모의실험 1,000회에서 명목 95% 신뢰구간의 경험적 포함률 92~98%
  • 동일 결과물 기준 평가·보고 시간 30% 단축
  • 신뢰구간 시각화·보고서와 웹 대시보드를 포함한 평가 시제품
